# Milestone 0.1: Backend Safety Net Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the backend reproducible to install and protected by an automated test suite that pins down today's behavior, including the two confirmed bugs, without changing how the app behaves.

**Architecture:** Pinned dependency files plus a README make setup repeatable. `database.py` reads `DATABASE_URL`, falling back to the current default, so tests can use a throwaway SQLite file. A pytest `conftest.py` provides a fresh database per test, a fake nutrition estimator (OpenAI is never called), a pinned UTC process timezone, and a FastAPI `TestClient`. Characterization tests record current endpoint behavior. The two known bugs are recorded as `xfail(strict=True)` tests that Phase 1 must turn green.

**Tech Stack:** Python 3.11, FastAPI 0.139, SQLAlchemy 2.0, Pydantic 2, pytest 8.4, httpx (for `TestClient`).

**Spec:** `docs/superpowers/plans/2026-09-24-mynutritionpal-roadmap.md` (Phase 0, "Immediate next step").

**Pre-verified:** this exact plan was dry-run on 2026-09-24 against a scratch copy of `backend/`: **19 passed, 3 xfailed**, identical with the process timezone set to UTC or to America/New_York. With `--runxfail`, the 3 known-bug tests fail with `assert 0 == 300`, `assert -779 > 0` and `assert -346 > 0`.

## Global Constraints

- Python **3.11** (the interpreter that already has the backend's packages; 3.11.7 was used for verification).
- Runtime pins, exactly: `fastapi==0.139.0`, `uvicorn==0.51.0`, `SQLAlchemy==2.0.52`, `pydantic==2.13.4`, `python-dotenv==1.2.2`, `python-multipart==0.0.32`, `openai==2.45.0`.
- Dev-only pins, exactly: `pytest==8.4.2`, `httpx==0.28.1`.
- **The only application code change in this milestone is `backend/database.py`.** No behavior changes, no refactors, no removal of debug prints or dead code (that is Milestone 0.2).
- The default database stays `sqlite:///./nutrition.db` when `DATABASE_URL` is unset.
- Tests must never call OpenAI and must never touch `backend/nutrition.db`.
- All commands run from `backend/` unless stated otherwise.
- Work on a branch, not `main`.

## Review Focus

1. **Tests pointed at the real `nutrition.db`.** `drop_all` would wipe it. Expected: the suite refuses to run. Pinned by the guard in `fresh_database` (Task 2, Step 3 proves it).
2. **Running the suite in the evening, or on a machine not set to UTC.** The timezone bug would make ordinary tests fail depending on the time of day. Expected: identical results in any timezone. Pinned by the UTC pin in `conftest.py` and by Task 6, Step 2.
3. **A test accidentally calling OpenAI** (cost, flakiness, the real key in `.env`). Expected: never. Pinned by the autouse `fake_estimator`, a dummy key set before `app` loads `.env` (`load_dotenv` does not override existing variables), and Task 5's assertion on what the fake received.
4. **A known bug silently fixed or masked later.** Expected: whoever fixes it must remove the marker on purpose. Pinned by `strict=True` on every `xfail`, and by Task 6, Step 3 checking each fails for the stated reason.
5. **Running pytest from the repository root.** Imports would fail because the backend uses flat module names. Expected: the README tells you to `cd backend`, and `pytest.ini` lives there. Documented only; not test-covered.

```python
import os
import tempfile
import time
from pathlib import Path

# Must be set before any app module is imported: database.py reads
# DATABASE_URL at import time, and the estimate route checks for a key.
os.environ["DATABASE_URL"] = "sqlite:///" + str(
    Path(tempfile.mkdtemp()) / "test.db"
)
os.environ["OPENAI_API_KEY"] = "test-key-not-used"

# Run the suite in UTC so "today" is the same date on the server clock
# and in stored UTC timestamps. Timezone tests override this.
os.environ["TZ"] = "UTC"
time.tzset()

import pytest
from fastapi.testclient import TestClient

import app as app_module
import routes.meals
from database import Base, engine
from schemas import NutritionEstimate

FAKE_ESTIMATE = NutritionEstimate(
    meal_name="Chicken and rice",
    calories=650,
    protein_g=45.0,
    carbohydrates_g=70.0,
    fat_g=15.0,
    confidence=0.8,
    calorie_low=550,
    calorie_high=750,
    assumptions=["1 cup cooked rice"],
)


@pytest.fixture(autouse=True)
def fresh_database():
    if engine.url.render_as_string() != os.environ["DATABASE_URL"]:
        pytest.exit(
            f"Refusing to run: tests are pointed at {engine.url}, "
            "not the temporary test database. Is DATABASE_URL read in database.py?"
        )
    Base.metadata.drop_all(bind=engine)
    Base.metadata.create_all(bind=engine)
    yield


@pytest.fixture(autouse=True)
def fake_estimator(monkeypatch):
    """Replace the OpenAI call; records what the route passed in."""
    calls = []

    def estimate(message, image_bytes=None, image_content_type=None):
        calls.append(
            {
                "message": message,
                "image_bytes": image_bytes,
                "image_content_type": image_content_type,
            }
        )
        return FAKE_ESTIMATE

    monkeypatch.setattr(routes.meals, "estimate_nutrition", estimate)
    return calls


@pytest.fixture
def fake_estimate():
    return FAKE_ESTIMATE


@pytest.fixture
def client():
    with TestClient(app_module.app) as test_client:
        yield test_client


@pytest.fixture
def server_timezone():
    """Switch the process timezone for one test, then restore UTC."""

    def set_timezone(name):
        os.environ["TZ"] = name
        time.tzset()

    yield set_timezone
    os.environ["TZ"] = "UTC"
    time.tzset()
```

```python
from schemas import ActivityLevel, Goal, Sex
from services.calorie_goal import calculate_bmr, calculate_daily_calorie_goal


def test_bmr_male_uses_mifflin_st_jeor():
    # 10*70 + 6.25*175 - 5*30 + 5
    assert calculate_bmr(Sex.male, age=30, weight_kg=70, height_cm=175) == 1648.75


def test_bmr_female_uses_mifflin_st_jeor():
    # 10*60 + 6.25*165 - 5*30 - 161
    assert calculate_bmr(Sex.female, age=30, weight_kg=60, height_cm=165) == 1320.25


def test_daily_goal_applies_activity_factor_and_goal_adjustment():
    result = calculate_daily_calorie_goal(
        sex=Sex.male,
        age=30,
        weight_kg=70,
        height_cm=175,
        activity_level=ActivityLevel.moderately_active,
        goal=Goal.lose_weight,
    )

    # BMR 1648.75 * 1.55 = 2555.56 -> 2556; minus 500 for lose_weight -> 2056
    assert result == {"bmr": 1649, "tdee": 2556, "daily_calorie_goal": 2056}
```

```bash
sed -i '' 's/return base + 5/return base + 6/' services/calorie_goal.py
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest tests/test_calorie_goal.py -q
```

`PYTHONDONTWRITEBYTECODE=1` is required. The mutation is the same size as the original, and the revert can land in the same second, so Python would otherwise reuse the mutated bytecode cache and later runs would still see `+ 6`. This was observed during plan verification.
